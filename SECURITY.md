# Security Policy

## Reporting a vulnerability

Please report security issues privately through GitHub's security advisory
feature instead of opening a public issue. Do not include real pairing tokens,
screen captures, private IP addresses, signing identities, or personal device
information in reports.

## Deployment scope

The bundled relay is intended for trusted local networks. It is not hardened
for direct exposure to the public internet. Use a properly authenticated and
encrypted reverse proxy before adapting it for remote access.
